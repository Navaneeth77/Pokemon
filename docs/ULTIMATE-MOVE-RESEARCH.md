# Ultimate move research

Game learnsets were checked for every playable base species. The candidate column lists moves that the available data associates with a single evolution line during the generation when they debuted. These are leads for review. They can include moves with incomplete records and do not establish anime exclusivity. A blank entry means the scan found no candidate, so anime and other official games are still worth checking before designing an original move.

Source data comes from [PokéAPI’s versioned learnsets](https://github.com/PokeAPI/pokeapi/blob/master/data/v2/csv/pokemon_moves.csv), [move metadata](https://github.com/PokeAPI/pokeapi/blob/master/data/v2/csv/moves.csv), and [evolution lines](https://github.com/PokeAPI/pokeapi/blob/master/data/v2/csv/pokemon_species.csv).
